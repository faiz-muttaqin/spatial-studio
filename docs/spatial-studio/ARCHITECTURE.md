# Architecture and implementation constraints

## Stack
TypeScript, React/Next, Three/R3F, Zustand/Zundo, Zod, Bun/Turbo, Biome, existing SQLite/IndexedDB. Keep headless core without runtime Three, registry-driven nodes, viewer/editor separation, old scene migrations, 2D/3D parity, imperative drag and metre-scale UVs (DECISIONS.md E-001/002/003/006/007/009). No new Go/Rust/WASM/Python service without evidence. Workers/TypedArrays first; optional Python/PyTorch in P5. Do not send raw meshes as LLM text.

## Data flow
1. Capture provider negotiates capabilities: browser camera/WebXR pose/depth/hit-test/optional raw camera; assisted photos and manual dimensions; optional native provider. Secure context and explicit permissions. Record missing capabilities, timestamps, coordinate transforms, units, tracking quality and confidence. Never imply photo-only mode has measured depth.
2. Store evidence in upstream CaptureSessionManifest V2 with clocks, coordinate frames, stream descriptors and artifact IDs. Raw bytes separate from scene JSON. Bounded chunks, downsampling, worker processing, resumable transfer when needed. Preserve source photographs and reference annotations. No auto uploads to AI.
3. Extract geometry: calibrated unprojection (verify depth convention), voxel downsample, outlier filtering, RANSAC planes, clustering, floor/ceiling/wall intersections, polygon extraction, least-squares measurement constraints. Nonorthogonal walls supported, uncertain/missing areas flagged. User marks openings and lamps if not detected. Scale against physical references; report raw and corrected errors independently.
4. Convert candidate geometry to Pascal's existing wall/slab/ceiling/zone/item nodes and capture reference layers. Stable IDs; preserve source evidence. User corrects dimensions and confirms visible elements. Sample approximate surface color; reference photos or manually cropped texture assignment first; calibrated projection when supported. Distinguish finish from hidden substrate, actual thickness and structural status (unknown unless verified). Do not infer roof, electrical wiring or exterior height from an indoor scan.
5. Approved as-built revision separate from raw evidence. Baseline correction creates a new revision; variants explicitly reference baseline and parent, never silently rebase. Reuse checkpoint/clone/persistence only after semantics verified.
6. AI agent reads compact semantic scene, dimensions, permissions, unknowns and optional rendered views/photos. Proposes variant operations; validates and renders, iterates, saves. Reuse furnishRoom/placeItems/spatial grid/verifyScene and existing tools. Typed operations, no generated executable code. Export using upstream formats where verified (JSON/GLB/IFC etc); SVG/DXF if needed after gap audit.

## Authority, locks and versioning
Single mutation authority for UI, MCP, CLI and persistence. Lock geometry, transforms, finish/material, deletion/reparenting independently. Protect parent transforms, bulk updates, imports, undo/restore, stale/concurrent writes. Reject invalid batch atomically, enforce revision precondition and keep audit trail. Unknown structural status defaults protected; agent cannot unlock without explicit user action. Block bypassing upstream write paths in protected variants until fixed. Preserve old scenes and original captures. Backup/export retains evidence IDs, permissions and revisions.

## Agent workflows and skills
Use upstream pascal-3d and furniture-fit first. Add scan inspection, evidence review, interior design/space planning, materials, visual lighting, validation and iteration only for gaps. Keep skill text/references separate from executable constraints/test fixtures. LLM uses room summaries, IDs, metres, coordinate convention, relational placement and dimensions, plus bounded screenshots. Geometry engine checks collision, room containment, door swing/clearance and walkable path when modeled; report unsupported checks. Use existing contract/operation/executor split, not duplicate MCP implementations. Local MCP one active client per service per upstream README; remote requires authentication, scoped revision/project access and compatibility test. Do not expose unverified public multi-tenant service.

## Operational design
One VM host, local-first browser editor + authenticated transfer across devices, optional native client. GPU not required for P1–P4. Data private by default, explicit user consent for external AI/photos, limits and retention, export/delete. Rendering previews are not measured lux. Physical simulation P6 needs photometry, reflectance, geometry and ground truth.
